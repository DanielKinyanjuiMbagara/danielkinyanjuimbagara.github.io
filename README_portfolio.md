# Daniel Kinyanjui Mbagara | Cybersecurity Portfolio

Personal portfolio showcasing my cybersecurity learning journey, hands-on labs and projects.

**Live site:** https://danielkinyanjui.tech

## What's on the site

- **Overview:** who I am and what I'm working toward (Junior Cybersecurity / SOC Analyst)
- **Resume:** experience, education, certifications and skills
- **Projects:** includes my ongoing 24-week HTB SOC Analyst learning path
- **Lab Challenges:** write-ups from Hack The Box Academy and TryHackMe, each with a problem statement, approach, tools used, completion screenshot and key lessons learned
- **Blog:** notes on what I'm learning and how I'm planning it
- **Contact:** email, LinkedIn and GitHub

Lab write-ups cover topics such as web application security, SQL injection, Active Directory, Splunk and SIEM, log analysis, digital forensics, malware triage, networking and Layer 2 attacks, and vulnerability assessment. Flags and answers are not published.

## How it's built

- A single static `index.html` file with HTML, CSS and JavaScript. There is no framework and no build step.
- Content (profile, resume, projects, labs, blog) is stored as JSON inside the page.
- Hosted free on **GitHub Pages** with a custom domain set in the `CNAME` file.

## Repository files

| File | Purpose |
| --- | --- |
| `index.html` | The whole site |
| `favicon.svg` | Browser tab icon (DK monogram) |
| `CNAME` | Custom domain for GitHub Pages. Do not delete |

## Updating the site

1. Open the site and click **Edit this site** to add or change content.
2. The page downloads an updated `index.html`.
3. In this repo choose **Add file → Upload files**, upload it (same file name) and commit.
4. GitHub Pages redeploys in a minute or two.
